# JS Web & Business - Landing Page & Portfólio 3D de Alta Conversão

> Website moderno, responsivo (mobile-first), com efeitos 3D interativos em WebGL (Three.js) e focado em captação de clientes para desenvolvimento de sites, catálogos e sistemas web. Criado por **Jhones Sandro** (@JhouSantana05).

---

## 🚀 Principais Recursos

1. **Hero Section 3D Interativo (Three.js)**:
   - Esfera holográfica em wireframe neon com anéis orbitais e campo estelar de partículas.
   - Reativo ao movimento do mouse e gestos de toque no celular.
   - Otimizado para não consumir bateria quando fora da área visível.

2. **Projetos Reais do GitHub (@JhouSantana05)**:
   - **Branch Clo**: Catálogo e e-commerce de moda streetwear (Next.js, TypeScript, Prisma, Tailwind CSS) com fotos reais das peças.
   - **Gestão Financeira Pro (Gest-o-30k)**: Dashboard completo para controle financeiro empresarial e pessoal com gráficos Chart.js, cálculo de metas (R$ 30k) e tela de login.
   - **Favela Chic**: PWA e WebApp de catálogo com câmera em tempo real para cadastro rápido de roupas pelo celular.
   - **Cartão de Visita Digital**: Hub comercial com foto oficial de Jhones Sandro, demonstrações de agendamento para barbearia e cardápio interativo para restaurantes.

3. **Foco Total em Vendas & Conversão Sem Complicação**:
   - Sem termos complexos ou automações desnecessárias: foco em **atendimento direto e humano pelo WhatsApp (11 95453-2927)**.
   - Botão flutuante de WhatsApp com aviso de atendimento online.

4. **Simulador Interativo de Escopo & Orçamento**:
   - O cliente seleciona o tipo de projeto e os adicionais desejados.
   - O simulador calcula o prazo estimado e gera um link que abre o WhatsApp já com o pedido pronto e formatado para você responder e fechar o contrato.

## 🌐 Como Publicar no Seu GitHub (@JhouSantana05)

1. Crie um repositório no seu GitHub chamado, por exemplo, `site-portifolio` ou `js-web-business`:
   ```bash
   git init
   git add .
   git commit -m "feat: site oficial JS Web & Business com projetos reais e 3D"
   git branch -M main
   git remote add origin https://github.com/JhouSantana05/NOME-DO-REPOSITORIO.git
   git push -u origin main
   ```
2. No repositório no GitHub, acesse **Settings** > **Pages** > selecione a branch `main` e clique em **Save**.
3. O site ficará no ar gratuitamente no link: `https://jhousantana05.github.io/NOME-DO-REPOSITORIO`.
